Two apps in one

Use the switch at the top to move between them. The app opens on the side you used last.

Watch

  • Home rows from your Stremio, CloudStream and Aniyomi sources
  • Hide any row and show it again with one tap
  • More like this, sequels and prequels on every title
  • Continue watching, saved across devices

Read

  • Library with categories you swipe between
  • New chapters and a release calendar
  • History grouped by day, with reading stats
  • Light novels and manga, with a Novel / Manga toggle

Both sides

  • ✨ For you suggestions based on what you watch and read
  • Check sources finds broken ones and turns them off, with undo
  • A warning before you install a plugin that's known to be broken
  • One Sources hub to add, pin and remove everything

How to install

Takes about a minute.

  1. Tap Download for Android above and get the newest .apk file.
  2. Open the file. If Android asks, allow installs from your browser or file manager.
  3. Add your own sources in Settings → Sources. The app doesn't come with any content.
  4. That's it. When there's a new version, a small pill appears. Tap Update.
